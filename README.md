# Seattle Convention Center Website

This repository contains work from the Seattle Convention Center website during a Drupal 8 migration and ongoing web maintenance period.

It is a legacy production codebase rather than a modern greenfield app, but that is part of what makes it useful context for my experience. Much of the work involved maintaining an established site, working within an existing CMS architecture, supporting content and frontend updates, and helping move the platform forward without disrupting day-to-day operations.

## Stack

- Drupal 8
- PHP
- Composer
- Drush
- JavaScript
- CSS
- HTML
- Apache configuration
- Git

The project is configured around Drupal Core 8.6 and Drush 9.5, with Composer managing the Drupal application and dependencies.

## What This Project Demonstrates

This repository reflects experience with:

- maintaining and updating a production CMS-backed website
- working within a large existing codebase rather than starting from scratch
- supporting a Drupal 7 to Drupal 8 migration effort
- frontend maintenance across HTML, CSS, and JavaScript
- PHP-based CMS development
- Composer-managed application dependencies
- working with configuration, deployment-oriented files, and established project conventions
- balancing technical changes with the needs of content, marketing, administrative, and business teams

## Context

At the Seattle Convention Center, my role crossed web development, CMS administration, design, and general technical support. The website work included regular content and frontend updates, Drupal maintenance, and migration support.

I keep this repository public as a snapshot of that period in my career. The framework and dependency versions are intentionally historical and should not be interpreted as a current Drupal starter project.

## Notes

The repository also includes Drupal's original documentation files and framework source. This `README.md` is intended as a quick portfolio-level overview of my involvement and the technical context of the project.
